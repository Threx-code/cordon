```
   pipx runpip cordon-scanner install --require-hashes -r <your pinned requirements>

   Container       ghcr.io/threx-code/cordon:0.6.0        amd64 and arm64; pin it by digest
   Runner          ghcr.io/threx-code/cordon-runner:0.6.0
   Bitbucket pipe  ghcr.io/threx-code/cordon-bitbucket-pipe:0.6.0
```

## Incoming code

```
   cordon-scanner clone URL        clone --no-checkout, scan the commit from git's objects,
                                   check out only if it passes; a blocked clone is removed
   cordon-scanner pull             fetch, scan what would be merged, merge only if it passes;
                                   a blocked pull leaves the checkout exactly as it was
   cordon-scanner guard install --global
                                   every clone and git init from now on carries post-checkout
                                   and post-merge hooks: a blocked pull, branch switch or clone
                                   is undone before anything has run it

   blocks   anything malicious; anything critical by default (--fail-on high to tighten)
   never    a cordon.yaml, policy or baseline inside the incoming code: it cannot configure
            its own check
```

Tutorial: [22 · Code arriving from someone else](https://github.com/Threx-code/cordon/blob/v0.6.0/tutorials/22-incoming-code.md).

## Measured

```
   every known-malicious record      249,646 records, 10 ecosystems, none missed
                                     (two were missed on the first run: a 213-character name
                                      and a 74-character version, cut short; fixed)
   real lockfiles against Trivy      1,687 lockfiles, 14 registries, 99.6% per package;
                                     every remaining difference sorted by cause, and most are
                                     Trivy listing what the build does not use
   found and fixed on the way        pnpm 10 lockfiles lost their whole tree · npm links named
                                     after their version · Go indirect modules left to go.sum ·
                                     Go never checked against the checksum database
```
