# Cordon 0.5.1

A home screen that reports the state you are in, and a `help` command.

```
   ┌──────────────────────────────────────────────────────────────────────────┐
   │  Detection is unchanged from 0.5.0: the same rulepack, the same          │
   │  advisories, the same findings. This release is the command line a       │
   │  person meets first, three commands that crashed or misled, and the      │
   │  data behind a future allowlist refresh.                                 │
   └──────────────────────────────────────────────────────────────────────────┘
```

```
  Map of this release
  ├─ Install ................ pipx · the Action · the container
  ├─ The home screen ........ what it reports, and where it reads it
  ├─ help ................... a command, an action, a misspelling
  ├─ Fixed .................. crashes, wrong command names
  └─ Verify it .............. hashes, signatures, provenance
```

## Install

```
   pipx install cordon-scanner==0.5.1          or, already installed:
   pipx runpip cordon-scanner install --require-hashes -r <your pinned requirements>

   GitHub Action   uses: Threx-code/cordon/action@v0.5.1   (pin the commit SHA the tag names)
   Container       ghcr.io/threx-code/cordon:0.5.1        pin it by digest in a pipeline
   Bitbucket pipe  ghcr.io/threx-code/cordon-bitbucket-pipe:0.5.1
```

## help

```
   cordon-scanner help                    this screen
   cordon-scanner help sbom               one command's help
   cordon-scanner help sbom generate      one action's help
   cordon-scanner help sbm                did you mean: cordon-scanner help sbom
```

## Fixed

```
   BEFORE                                                  NOW
   cordon-scanner config | report | baseline               each prints its own help, exit 3
     → "internal error: AttributeError … a bug in cordon"
   cordon-scanner agent | intel | sbom | bundle |          each prints its own help, exit 3
     advisories → one terse line
   whoami, sign-in errors, --judge and --upload help,      they say cordon-scanner login;
     several hints → "run `cordon login`" (no such         a test now fails if a message
     command; `cordon` on PyPI is another project)         names a `cordon` command
   cordon-scanner help → "invalid choice"                  the help command above
   every subcommand's --help → plain argparse              coloured headings, flags, values
```

```
   MAINTENANCE (not in the package, no released scan changed)
   the allowlist refresh read a rate-limited registry (HTTP 429) as the end of the list;
   pub.dev and RubyGems are now paced and retried, and an unreadable page fails its
   ecosystem instead of shortening it
```
